## 1. Цель первой версии (v0.1)

Работающая система прослеживаемости товара с:
- Регистрацией и авторизацией персонала по ролям
- Доступом с телефона и компьютера через обычный браузер (без установки приложений)
- Полным циклом сканирования: склад → отгрузка → представитель в городе → доставка клиенту
- Историей событий по каждой коробке (кто, когда, где, что сделал)
- Постоянным доменом с HTTPS (без временных туннелей для тестов)

---

## 2. Ключевые решения

### 2.1 Аккаунты персонала

- У каждого сотрудника — отдельный аккаунт с ролью: `ADMIN`, `MANAGER`, `WAREHOUSE` (кладовщик), `PN` (представитель в городе)
- Вход по **email ИЛИ телефону** — что удобнее человеку, второе поле не требуется
- Действия при сканировании ограничены ролью:
  - `WAREHOUSE` — принять на склад, отгрузить
  - `PN` — принять у себя в городе, подтвердить доставку клиенту
  - `ADMIN`/`MANAGER` — все действия

### 2.2 Способ доступа с телефона

**Решение: обычный сайт (веб) + PWA-обёртка, без Telegram-бота и без нативного приложения.**

Обоснование:
| Вариант | Время на реализацию | Комментарий |
|---|---|---|
| Сайт (веб) + PWA | Малое — почти всё уже готово | Камера, вход, роли уже частично реализованы. PWA добавляет иконку на экран телефона без публикации в сторах |
| Telegram-бот / Mini App | Высокое — фактически дублирование интерфейса заново | Плюс только в push-уведомлениях, которые можно получить и от сайта |
| Нативное приложение (React Native и т.п.) | Очень высокое — месяцы | Не вариант при сроке 11 дней |

### 2.3 Затраты

| Статья | Стоимость | Обязательность |
|---|---|---|
| Домен | ~5 000–8 000 ₸/год | Обязательно |
| VPS-сервер | ~2 000–8 000 ₸/мес | Обязательно |
| SSL-сертификат | Бесплатно (Let's Encrypt / Cloudflare) | Обязательно, но бесплатно |
| SMS-коды для входа | Платно за сообщение | Не требуется для v0.1 — вход по паролю достаточен |

**Итого обязательных расходов:** ≈ 3 000–10 000 ₸/месяц (домен + VPS)
